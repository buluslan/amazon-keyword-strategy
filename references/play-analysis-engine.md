# 打法分析引擎

> **何时读**：SKILL.md Step 3 打法分析时。
> **做什么**：标品/非标品分治 → 作战图输出。标品打法完整（词根分类 + 四象限 PPC）；非标品出判别结论 + 基础作战图。
> **前置依赖**：Step 2 已完成标品/非标品判别（判别细则见 `standard-vs-nonstandard.md`）。

---

## 0 · 输入与降级规则

分析层接收统一 schema 的词表。字段按可用性分两档：

| 档位 | 所需字段 | 来源 | 缺失行为 |
|---|---|---|---|
| **基础层** | 关键词 | 全源都有 | 永不停摆，核心逻辑跑通 |
| **增强层** | 搜索量 / 竞争指标 / 转化率 / 竞价 | 按数据源能力（见 `adapter-interface.md`） | 缺失标 `[缺失]`，对应分析降级但不报错 |

**铁律**：
- 只有关键词也能产出基础作战图（词根分类 + 匹配建议 + 否定词 + 阶段性）。
- 增强字段缺失时标 `[缺失]`，**绝不脑补数字**。
- 未实测的竞争/转化阈值标 `⏳`（下文给的是经验区间，非实测标定）。
- **原始字段透传**：keywords 保留输入的全部原始字段，判定字段是增量不是替换（细则见 `generic-schema.md` 原始字段透传节）——原始数据 sheet 留底与下游二次分析依赖它。

## 1 · 标品打法（开源完整）

标品的出单词集中（前 5 词占多数出单），核心逻辑：**词频统计 → 识别核心词根 → 竞争强度筛强相关 → 否定词识别 → PPC 策略**。

### 1.1 词频统计 → 识别核心词根

1. 对反查到的全部关键词做分词 + 词频统计。
2. 按词根六分类归类（共六类：共性 / 属性 / 品牌 / 品类 / 受众 / 否定，细则见 `word-root-classification.md`）。属性词带维度标注（`属性·<维度>`，维度从本次词库现场归纳）。
3. 高频词根 = 核心词根。核心词根是后续匹配建议和 PPC 分配的锚点。

**判断空间**：词根归类有语义判断，Agent 按分类规则判断，不强求机械匹配。边界词根（可归两类）归到更贴近购买意图的一类。

### 1.2 竞争强度筛强相关

有竞争指标时（增强层），竞争分由 **render 确定性打分**（公式与固定切点见 `battleplan-template.md` §3.1），Agent 不判档位：

| 可用指标（按数据源拿到的） | 含义 |
|---|---|
| 点击集中度（competition.click_concentration / top3_click_share） | 头部垄断程度，高 = 难切入 |
| 商品数（products / coverage_ratio） | 竞品密度，高 = 拥挤 |
| competition.spr | 进入难度，高 = 难排 |

**Agent 职责**（打分之外的部分）：
- 确保原始竞争指标**透传**进 keywords（原始字段透传铁律）——竞争分的输入。
- `data_notes` 补充源口径解释（如"占位率=该词前排被 N 个竞品占据比例"），指标清单本身由 render 自动生成，不手填。
- 指标全缺的词竞争强度 `[缺失]`，PPC 建议降级为仅按匹配类型给。

### 1.3 否定词识别

满足任一条件 → 进否定词表：

| 条件 | 判定字段 | 否定类型 |
|---|---|---|
| 与产品不相关 | 词根归类为"否定"类（语义不匹配） | 精准否定 |
| 高搜索低转化 | 搜索量有、转化率显著低于均值 `⏳` | 精准否定 |
| 有曝光无转化 | 反查有词但转化数据为 0 | 词组否定 |

转化率字段缺失时，只按"不相关"做否定，不按"低转化"做否定（避免误杀）。

**词根级否定**：同族否定词（共享否定词根，如 adapter 族）归组填"所属否定词根"，优先建议词组否定——否一个词根批量拦截整族衍生长尾。

### 1.4 PPC 策略（四象限）

有搜索量 + 竞争强度时，按四象限给 PPC 策略：

```
                    竞争强度低              竞争强度高
              ┌─────────────────────┬─────────────────────┐
  搜索量高    │ 🟢 蓝海核心词        │ 🟡 精准控预算        │
              │   主攻，精准+词组    │   只开精准，卡位    │
              ├─────────────────────┼─────────────────────┤
  搜索量低    │ 🟡 长尾词            │ 🔴 不打              │
              │   广泛/词组捡量      │   除非高转化才上     │
              └─────────────────────┴─────────────────────┘
```

- **🟢 蓝海主攻**：高搜索 + 低竞争。预算优先倾斜，精准匹配抢排名，词组匹配扩量。
- **🟡 精准控预算**：高搜索 + 高竞争。只开精准，出价保守，不铺广泛（烧钱）。
- **🟡 长尾广泛**：低搜索 + 低竞争。开广泛/词组捡量，低出价铺面。
- **🔴 不打**：低搜索 + 高竞争。默认放弃。**例外**：若转化率显著高 `⏳`，可小预算精准试投。

`ppc_quadrant` 由 render 按 **ABA层级 × 竞争强度档** 确定性交叉计算（量高=大词/中词）：蓝海主攻 / 精准控预算 / 长尾广泛 / 不建议打，Agent 不逐词标注。四象限的阈值不再是 Agent 即兴判断——量档与竞档都来自固定界限。

**词根级广告组**（判断类，建议项）：同词根的词倾向放同一广告组——词根是流量源头，同族词分开投会在广泛/词组匹配下同广告组外自相竞争。md 总结的广告架构建议按核心词根给分组方向，经 `payload.strategy_summary` 注入（两段式 md，见 battleplan-template.md §3.6）。

搜索量或竞争强度缺失时，降级为按词根类型 + 匹配建议给策略（不给四象限定位）。

### 1.5 阶段性标记

`stage` 是**词维度**属性：该词适合在产品的哪个阶段主打——不是"产品当前处于哪个阶段"（后者是另一个概念，需趋势数据才可判）。两类判定依据：

| 依据 | 强度 | 行为 |
|---|---|---|
| 产品实际上架时间 / 销量趋势（增强层） | 强 | 判定产品当前阶段，按阶段表给各词策略侧重，不带 ⏳ |
| 词规模分布（长尾竞争小适合新品期先打，大词需权重起来后打） | 弱 | 按词规模推断，档位标 `⏳`，且 `data_notes.stage_basis` 注明"按词规模推断"——用户需知道这是推断不是实测 |

| 阶段 | 特征 | 策略侧重 |
|---|---|---|
| **新品** | 上架 < 3 月，评论少 | 精准打核心词建基础排名；不铺广泛（预算散） |
| **成长** | 出单上升，评论积累中 | 核心词精准 + 长尾词词组扩量；开始捡蓝海词 |
| **成熟** | 排名稳定，评论充足 | 防守核心词位 + 蓝海词主攻；控 ACOS |
| **衰退** | 出单/排名下滑 | 收缩预算到仍转化的词；砍长尾；不追新词 |

两依据都无 → 标"阶段待定"，不给策略侧重。

**判断空间**：阶段边界不是死日期，Agent 结合可用数据（上架时间、BSR 趋势、评论增速）综合判断；弱依据推断时保持 ⏳ 标注，不把推断当实测。

## 2 · 非标品打法

非标品的出单词分散（几百词各出几单），精准打法效率低。本 skill 对非标品输出：

1. **完成判别**：输出"该品类为非标品"，给判别依据。
2. **基础作战图**：词根分类 + 词频统计 + 匹配建议 + 否定词（基础层能力）。
3. **匹配建议偏移**：非标品的匹配建议偏广泛/词组铺长尾（出单词分散，精准打法单点效率低），否定词判定逻辑同标品。

## 3 · 作战图生成

### 3.1 标品作战图（4 部分）

**① 精准词表**

| 字段 | 来源 | 缺失处理 |
|---|---|---|
| 关键词 | 全源 | 必有 |
| 词根类型 | 自算（六分类，属性词带维度） | 必有 |
| 建议匹配 | 自算（按词根 + 竞争） | 必有 |
| 建议动作 | 自算（综合判断） | 必有 |
| 搜索量 | 增强层 | `[缺失]` |
| ABA排名 | 增强层 | `[缺失]` |
| ABA 层级 | render 固定界限切档（≤1万大/1万~10万中/10万~50万小/>50万长尾；无排名按本表搜索量分位兜底） | 排名与搜索量都缺 `[缺失]` |
| 竞争分 / 竞争强度 | render 确定性打分（公式见 battleplan-template.md §3.1；切点 ≥70高/40~69中/<40低） | 指标全缺 `[缺失]` |
| 阶段性标记 | 词维度（强依据=趋势数据，弱依据=词规模推断标⏳，见 §1.5） | 两依据都缺 → "阶段待定" |

**④ 数据口径说明（`data_notes`，分析阶段必产出）**

判定依据要对用户可见——输入指标（点击集中度/占位率等）参与竞争分计算后，用户看到的只剩档位，依据必须可见：**竞争强度本次实际依据的指标清单由 render 自动生成**（基于打分实际命中的指标槽，保证口径与计算一致）；搜索量时间单位（周/月）、阶段性的数据基础、⏳ 待确认项清单（如按词频推断的本品接口）由 Agent 注入。render 把 `data_notes` 渲染进字段说明 sheet 和 md 判读说明节。

**② 否定词表**：关键词 | 否定原因 | 否定类型（精准/词组）

**③ PPC 策略建议**：四象限定位 + 预算侧重 + 阶段策略

### 3.2 非标品作战图

基础作战图（词根分类 + 词频 + 匹配建议 + 否定词）+ 非标品判别结论；匹配建议偏广泛/词组铺长尾。

### 3.3 两层输出

| 层 | 所需输入 | 输出内容 | 停摆条件 |
|---|---|---|---|
| **基础层** | 关键词 | 词根分类 + 匹配建议 + 否定词（不相关类）+ 阶段标记（待定） | 无关键词（不给空图） |
| **增强层** | 搜索量 + 竞争 + 转化 | 四象限 PPC + 蓝海词识别 + 否定词（低转化类）+ 阶段策略侧重 | 增强字段缺失则该部分降级 |

字段全则输出全；字段缺则对应分析降级，基础层始终产出。

## 4 · 措辞边界

**取数/计算类（钉死执行，Agent 无判断空间）**：
- 反查拉词：必须走适配器，数据源不可用 → 提示上传词表，**绝不脑补词**。
- 字段降级：增强字段缺失 → 标 `[缺失]`，**绝不编数字**。
- 数值分档：ABA 层级（固定界限）/ 竞争打分（公式 + 固定切点）/ PPC 四象限（档位交叉）由 render 确定性计算——同一输入永远同一输出，Agent 不判数值档位、不即兴发明分位规则。
- 落盘输出：固定路径 `output/{ASIN}_{日期}/`，固定三件套（xlsx + md + json）。

**判断类（给 Agent 空间，有标准但不机械）**：
- 标品/非标品判别：按三维度综合判断，不强求硬阈值。
- 词根归类：按六分类规则语义判断，边界词归更贴近购买意图的一类。
- 阶段判定：结合可用数据综合判断，边界不是死日期。
- 策略运用：四象限/档位之上的打法选择（预算倾向/主攻取舍/广告组归组）。

**原则**：数值分档归脚本（可复现），语义判断归 Agent（有标准但不机械）——这样档位可审计、判断可追责。

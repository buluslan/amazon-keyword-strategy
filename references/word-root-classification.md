# 词根六分类

> 触发时机：Step 3 打法分析，对词库每个词标注词根类型。
> 数据要求：只需关键词字段，全数据源可用，永不停摆。

## 定位

词根分类回答"这个词在广告里扮演什么角色"。六类正交，每个词归一类。分类结果驱动后续：匹配类型建议、广告用途、是否进词表。

分类是语义判断，只吃关键词本身，不依赖搜索量/竞争/转化等增强字段。增强字段影响打法建议，不影响分类——无增强字段时分类照常跑。

## 六类规则

| 词根类型 | 判断标准 | 广告用途 |
|---|---|---|
| 共性词根 | 产品最基础叫法，绝大多数同类 ASIN 都含 | 必须覆盖，广泛+词组+精准分层投放 |
| 属性词根 | 修饰规格/特性/功能，能与共性词组合成词 | 精准投放，"小词带大词"策略核心载体 |
| 品牌词根 | 竞品品牌名（含变体/拼写错误） | 精准截流，独立广告组，单独预算 |
| 品类词根 | 同类产品的其他叫法/上位词 | 广泛覆盖 |
| 受众词根 | 用户身份/使用场景/人群标签 | 精准首选 + Sponsored Brands 人群定向 |
| 否定词根 | 与产品不相关、前台跑偏、转化极低 | **直接进否定词表，不入词表** |

## 识别方法

### 共性词根
- 剥掉所有修饰后那个最基础的核心词，就是共性词根
- 词频统计辅助：词库内出现频次最高、且能和其他词根自由组合的，通常是共性词根
- 验证：绝大多数同类 ASIN 反查词里都含

### 属性词根（两层：维度 → 取值）
- 识别修饰类成分：规格（尺寸/容量/颜色/数量）、特性（防水/无线/便携）、功能（充电/降噪）
- 能跟共性词组词 = 属性词根
- 词频统计辅助：高频出现的修饰类 token，常与共性词共现
- **两层打标**（`word_root` 值细化）：
  - **维度层**：买家按什么挑产品——标注为 `属性·<维度>`，如 `属性·尺寸`、`属性·材质`、`属性·风格`、`属性·功能`、`属性·场景`
  - **取值层**：该维度下的具体需求（queen / boho / waterproof），体现在词本身；各维度的取值分布由作战图「词根汇总」sheet 聚合呈现（token 级统计，render 自动完成）

> **维度现场归纳（设计红线）**：维度从本次词库的 token 分布现场归纳——上面的维度示例仅帮助理解"维度"是什么，遇到示例外维度（3C 的接口、服装的版型、宠物的品种）直接自造标签。槽位封闭、内容开放：固定的是"维度→取值"结构，开放的是维度内容，不维护任何品类维度清单。

### 品牌词根（双分类，处理相反）
先判断品牌词是**本品**还是**竞品**——两者打法完全相反，混为一谈是高频踩坑：

| 子类 | 判定 | 处理 | 广告用途 |
|---|---|---|---|
| **本品品牌** | == Step 0 确定的本品品牌（含品牌名的常见变体/缩写/拼写错误） | **不进品牌桶**；该词按剩余语义成分归共性/属性 | **主攻**——自有品牌词是核心流量，绝不能截流 |
| **竞品品牌** | 词库中专有名词 ≠ 本品品牌、也非兼容生态（其他品牌名，含变体） | 归品牌词根 | 精准截流，独立广告组，单独预算 |
| **兼容生态品牌** | 本品为第三方兼容款（Step 0 确认的品牌≠原厂，但产品兼容原厂设备）时，词库中的**原厂品牌词族** | 归品牌词根，标兼容生态子类 | **默认截流**——精准+控预算+独立广告组+单独预算；有转化数据且显著高于均值 ⏳ 的词可升主攻（标⏳注明依据） |

- 本品品牌来源（**先看输入 ASIN 的归属**，按序兜底）：
  - **输入 ASIN 是本品**（老品诊断场景）：① 从该 ASIN 详情取 brand ② 详情未返回 → 问用户一次 ③ 未答 → 从词库最高频专有名词推断，标 `⏳[待确认]` 并注明推断依据
  - **输入 ASIN 是竞品**（新品建库/竞品拆解场景，按 SIF 类工具的常见用法用户拿来反查的 ASIN 是参考竞品）：**问用户优先**——竞品详情里的 brand 是竞品的品牌，直接采用会把竞品品牌误当本品（误截流自家核心流量词的反向翻车）。竞品词库的高频品牌词仅作辅助推断，标 `⏳[待确认]`
  - **词表/粘贴输入**（无 ASIN）：问用户一次 → 未答 → 词频推断标 `⏳[待确认]`
- **误截流自有品牌词的代价**：卖品牌产品时品牌词占词库大头，全截流等于放弃核心流量。凡词库中某品牌词出现频次显著高于其他品牌词，优先怀疑是本品品牌
- **品牌变体识别用"专名组合+语义豁免"，不用产品线枚举**：枚举式匹配（逐个列产品线/代际变体）覆盖不了分写/引号/拼写变体长尾，会成批漏网——正确姿势是识别专名组合（含分写与拼写变体）再按语义条件豁免（如含线材语义则捞回）。
- **兼容款的高频品牌词≠本品品牌**：第三方兼容款场景，频次最高的品牌词往往是原厂品牌（兼容生态流量），不是本品品牌——按兼容生态行处理，勿因高频升格为本品品牌。兼容款判定在 Step 0 品牌确认时完成（用户说明"第三方兼容"即触发）
- 不确定某专有名词是否品牌 → 标 `[待确认]`，不臆断

### 品类词根
- 同类产品的其他说法、上位品类词、相邻场景词
- 比共性词根更泛或更偏，不能当核心词打

### 受众词根
- 用户身份：men / women / kids / gift for…
- 使用场景：office / travel / wedding
- 人群标签：professional / beginner

### 否定词根
四类信号识别：
1. **语义不相关**：词义指向其他品类或完全不搭
2. **前台跑偏**：搜这个词跳出无关结果——需实际搜索验证，无验证条件标 `⏳`
3. **转化极低**：有转化数据时，长期 0 转化或显著低于均值——无转化数据时不靠这条判
4. **规格不匹配的词**：词里的规格/接口指向本品不具备的型号——两类：配件词（adapter / converter / cable 一类，示例词非预置清单，仍需对照本品规格逐一甄别）和**同品类异规格词**（品类对了但规格版本与本品不符）。**前置依赖**：先完成本品规格锚点确认（见下节），未确认前规格类词不武断否定、降观察标 ⏳。**高频踩坑点**：配件词"看着相关"易漏判；同品类异规格词"品类对了"更容易漏判（成批错主攻），必须对照本品规格逐一甄别。

### 本品规格锚点确认（Step 0 前置，与品牌确认并列）
哪些规格是"硬约束"由品类现场判断，不预置清单（3C 看接口/机型，服装看尺寸/版型，食品看口味/规格——Agent 从词库 token 分布识别本品类买家在按什么维度挑产品）。确认链（按序兜底）：

1. 本品 ASIN 输入时从该 ASIN 详情/标题取规格（**竞品 ASIN 的详情取到的是竞品规格，不能直接当本品锚点**——同品类竞品规格常常不同，正是要甄别的对象）
2. 问用户一次
3. 未答 → 从词库高频规格词推断，标 `⏳[待确认]` 并注明推断依据

确认后的用法：规格不匹配的词族（配件词 + 同品类异规格词）按否定处理，归入否定词表对应词根族；未确认（⏳）时规格类词降观察，不武断否定。

## 否定词根的特殊处理

否定词根是唯一不入词表的类型。识别即分流到否定词表，不参与后续分层/匹配建议。

否定类型判定：
- 明确不相关 → 精准否定
- 泛化跑偏（一词多义易误匹配）→ 词组否定
- 转化极低但语义相关 → 词组否定（保留精准截流可能）
- 转化数据缺失 → 默认词组否定，标 `[缺失]`

**词根级否定（族拦截）**：同族否定词（共享同一否定词根，如 adapter 族）在否定词表归组——填"所属否定词根"列，优先建议词组否定。否一个词根即可批量拦截该词根衍生的整族长尾，比逐词精准否定省操作且覆盖完整。

## 数据源无关性

词根分类只吃关键词字段，换数据源只影响字段填充，不影响分类规则。这是基础层能力——搜索量、竞争、转化全缺，六分类照常出。

## 辅助手段：词频统计

把词库所有词打散成 token，统计各 token 出现频次，辅助共性/属性识别：
- 高频且能自由组合 = 共性词根候选
- 高频修饰类 token = 属性词根候选
- 低频专有名词 = 品牌词根候选（需校验，别把生僻属性词误判品牌）

词频是辅助不是判定，最终归类靠语义。频次数据缺失不影响分类。
